Chatter Datetime

This module provides exact date and time display in the Odoo chatter instead of showing relative days like "2 days ago" or "yesterday". It helps users track messages with precise timestamps for better message organization and audit trails.

Designed for Odoo 18, this lightweight module enhances the chatter experience by displaying both the exact datetime and relative time, giving users the flexibility to see precise timestamps when needed while maintaining the familiar relative time display.

If you need to track message timestamps accurately, maintain better audit trails, or simply prefer seeing exact dates and times in your chatter messages, this module provides a simple and effective solution.

Chatter Datetime Installation

Go to the Apps menu in Odoo.

Remove the Apps filter and search for Chatter Datetime.

Click Install.

The module will be installed and activated automatically. No additional configuration is required.

How It Works

Once installed, the module automatically modifies the chatter message display to show exact date and time. You'll see both the precise timestamp and the relative time in all chatter messages.

Before Installation:

  • Chatter messages show: "2 days ago", "yesterday", "3 hours ago"
  • Only relative time is displayed

After Installation:

  • Chatter messages show: "Dec 15, 2024, 10:30 AM - 2 days ago"
  • Both exact datetime and relative time are displayed
  • Hover over the timestamp to see the full datetime in the tooltip

The exact datetime appears before the relative time, making it easy to see precise timestamps at a glance.

Chatter Display Example

In any Odoo record with chatter enabled (Sales Orders, Invoices, Contacts, etc.), you will now see messages with enhanced datetime display:

  • Message Header: Shows author name and exact datetime
  • Timestamp Format: "MMM DD, YYYY, HH:MM AM/PM - X days ago"
  • Tooltip: Hover over the timestamp to see the full datetime string

This enhancement works across all Odoo models that use the mail/chatter system.

Frequently Asked Questions

1. What is Chatter Datetime?

Chatter Datetime is an Odoo 18 module that enhances the chatter message display by showing exact date and time instead of just relative days. It displays both the precise timestamp and the relative time, giving users better visibility into when messages were posted.

2. What are the system requirements?

  • Odoo 18.0 or later
  • Required Odoo module: mail (usually installed by default)

3. How do I install the module?

Go to Apps menu, remove the Apps filter, search for "Chatter Datetime", and click Install. No additional configuration is required - the module works immediately after installation.

4. Does this module change existing functionality?

No, the module extends the mail.Message template to add exact datetime display while maintaining the existing relative time display. It doesn't break any existing functionality and works seamlessly with Odoo's mail system.

5. Will this work with all Odoo models?

Yes, the module works with any Odoo model that uses the mail/chatter system, including Sales Orders, Invoices, Contacts, Projects, Tasks, and any custom models with chatter enabled.

6. Can I customize the datetime format?

The module uses Odoo's standard datetime formatting (datetimeShort property). Customization would require modifying the module's template file. The current format follows Odoo's localization settings.

7. Does this affect performance?

No, the module is lightweight and only modifies the display template. It doesn't add any database queries or processing overhead, so there's no performance impact.

8. Is this compatible with other mail-related modules?

The module uses template inheritance, which is the standard Odoo way of extending views. It should be compatible with most mail-related modules, but if you encounter conflicts, please contact support.

9. Can I uninstall the module?

Yes, you can uninstall the module at any time through the Apps menu. Uninstalling will restore the default chatter display (relative time only) without affecting your data.

10. What if I only want exact datetime without relative time?

The current version displays both exact datetime and relative time. If you need only exact datetime, you would need to modify the module's template file. Contact support if you need assistance with customization.
